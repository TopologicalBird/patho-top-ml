# Supplementary Figures
## Trustworthiness for multiple neighborhood sizes
![trustworthiness.pdf](trustworthiness.pdf)

Visualization of trustworthiness values for multiple neighborhood sizes with different frameworks. U+T, U+C, and full have higher trustworthiness compared to other frameworks. When comparing U+T and U+C, in smaller neighborhood sizes, U+C performs better, and in larger neighborhood sizes, U+T performs better. This change takes place around $k=50-100$.

## Pointwise trustworthiness for multiple neighborhood sizes
![pointwisetrustworthiness.pdf](pointwisetrustworthiness.pdf)

Visualization of pointwise trustworthiness values for multiple neighborhood sizes with different frameworks. U+T and full have fewer low trustworthiness points and more high trustworthiness points compared to others. Based on this and previous results, we can say that U+T and full are the best performing frameworks under our evaluation setting.

## Stable points with different threshold values
![stablepoints.pdf](stablepoints.pdf)

We can use pointwise trustworthiness information to select stable parts of the distributions by rejecting points with minimum pointwise trustworthiness below a threshold value (minimum is taken for all pairs and for multiple $k$ values). From the full validation data result, U+T and full seem to be able to achieve minimal data loss supported by high stability. We might also want to focus on tub & por part because gradational distribution is especially important in these subtypes. We can see a similar trend in this subset data; U+T and full achieve minimal data loss.

## Visualization of the output distributions
![distribution.pdf](distribution.pdf)

Visualization of the output distributions generated by U+T. Top row shows distributions of full validation dataset. Black points are the unstable points with pointwise trustworthiness threshold value 0.4. Bottom row shows distributions without the black points.
